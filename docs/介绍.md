面向 Agent 工作流的执行监控与质量评估平台设计与实现

课题简介：随着 AI Agent 在软件开发和业务应用中的不断普及，如何监控其执行过程、分析运行状态、评价任务完成质量，已成为 Agent 工程化落地面临的重要问题。本课题拟设计并实现一个面向 Agent 工作流的执行监控与质量评估平台。系统能够采集 Agent 执行过程中的任务状态、模型调用、工具调用、执行轨迹、Token 消耗及异常信息，提供完整的执行过程追踪、资源消耗统计和失败原因分析。在此基础上，进一步建立 Agent 执行质量评价机制，通过设置不同的执行策略和测试任务，比较其任务成功率、执行效率、资源成本及运行可靠性。学生需要完成数据采集、执行轨迹管理、监控分析、质量评价和可视化展示等核心模块。通过本课题，可以深入理解 AI Agent 的运行机制，掌握软件可观测性、性能监控和质量保障技术。
